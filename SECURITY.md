# Security policy

## Reporting a vulnerability

Email [security@craigdevjohnson.com](mailto:security@craigdevjohnson.com) to report
a suspected vulnerability privately. Keep sensitive details out of public issues
and pull requests.

Include the affected revision, potential impact, and reproduction steps or a
minimal proof of concept. Do not include live credentials or personal data.

Security fixes target the current `main` branch. No release support policy has
been established yet.
